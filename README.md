# whatsapp_clone

Hi, im just an average student who wants to learn about anything about technology.

This is a **mobile application project** that two other friends and I created for our **first campus internship** at **PT. Kreasi Putra Hotama**.

## Getting Started

In this project, we focused on learning the fundamentals of mobile application development with Flutter. We worked on this project for 5 weeks (1 month+).

---

### In Week 1

We focused on learning:

- Git and GitHub basics
- Dart language basics
- Android emulator creation
- Basic application building widgets, such as MaterialApp, Scaffold, etc.
- Creating a UI related to the application we were imitating, WhatsApp.

### In Week 2

We focused on learning about our own API (API Endpoint) using Golang.
For the end point, you can check it here: [WhatsApp_Clone API](https://github.com/AlatBekam/whatsapp_clone_API)

- Creating an API Endpoint with Golang
- Learning about HTTP in Flutter
- Learning about CRUD in Flutter

### In Week 3

We focused on improving the application we created.

- Learn how to handle HTTP Status in Flutter
- Learn how to display images in Flutter
- Learn how to store images on the backend using APIs
- Learn how to create controllers for each service in our application

### In Week 4 and 5

We focused on finalizing the application, emphasizing bug finding and fixing them

- Learn how to handle APIs such as loading, error, success, and empty conditions
- Learn about Storage Handlers, such as image and camera permissions
- Learn about themes that can adapt to device defaults or manual controls
- Learn about testing application features

---

In this project, we were essentially focused on **learning everything a mobile developer** needs to understand. Therefore, we **didn't create a complete WhatsApp clone**, only **specific sections**, such as chat, status, and community.
